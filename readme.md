# Movie Review Sentiment Classifier

A text classification pipeline that predicts whether a movie review is positive or negative, served through a live API with a simple web interface.

## Overview

Given a review like *"this movie was absolutely brilliant"*, the model predicts its sentiment along with a confidence score. Built end-to-end: data preprocessing, feature extraction, model training, evaluation, and deployment behind a REST API.

## Result

**90.1% accuracy** on a held-out test set of 10,000 reviews (never seen during training).

## Tech stack

- **Python** — pandas, scikit-learn
- **Model** — Logistic Regression
- **Features** — TF-IDF vectorization
- **API** — FastAPI
- **Frontend** — plain HTML/CSS/JS
- **Dataset** — [IMDB Dataset of 50K Movie Reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)

## How it works

1. **Preprocessing** — strip HTML artifacts (`<br />` tags) left over from scraping, and map `positive`/`negative` labels to `1`/`0`.
2. **Train/test split** — 80/20 split, so the model is evaluated on data it never trained on.
3. **Vectorization** — TF-IDF converts review text into weighted word-frequency vectors, fit only on the training set to avoid data leakage.
4. **Training** — a Logistic Regression classifier learns which words push a review toward positive or negative.
5. **Evaluation** — accuracy measured on the test set; misclassified examples inspected manually.
6. **Serving** — the trained model and vectorizer are saved to disk (`joblib`) and loaded once at API startup. A `/predict` endpoint transforms new text and returns a prediction.

## Project structure

├── index.html         # simple web UI

## Running it locally

1. **Install dependencies**
   ```bash
   pip install pandas scikit-learn fastapi uvicorn joblib regex
   ```

2. **Download the dataset** from Kaggle (link above) and place it in the project folder as `IMDB_dataset.csv`.

3. **Train the model**
   ```bash
   python3 main.py
   ```
   This preprocesses the data, trains the classifier, prints accuracy, and saves `model.pkl` and `vectorizer.pkl`.

4. **Start the API**
   ```bash
   uvicorn api:app --reload
   ```

5. **Try it**
   - Open `http://127.0.0.1:8000/` for the web UI, or
   - Open `http://127.0.0.1:8000/docs` for the interactive API docs.

## Example request

```bash
curl -X POST http://127.0.0.1:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"review": "This movie was a complete waste of time."}'
```

```json
{"answer": "negative", "confidence": 0.94}
```

## What I'd improve with more time

- Compare TF-IDF + Logistic Regression against a pretrained transformer (e.g. DistilBERT) to see how much accuracy is left on the table.
- Handle mixed/sarcastic reviews better — most misclassifications come from reviews with conflicting sentiment cues.
- Add automated tests and Dockerize the API for easier deployment.
